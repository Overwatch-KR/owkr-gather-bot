# 문의·개인정보 수정·삭제 요청 안내

> 공개 전 초안 — 연락처와 처리 수단이 마련되기 전에는 지원 창구로 게시하지 않습니다.

최종 검토일: 2026-10-27

## 현재 봇에서 제공하는 경로

서버의 `/개인정보`에서 본인 티어 삭제 확인 버튼과 보관 안내를 제공합니다.
이 버튼은 현재 참가한 내전의 티어 재수집도 차단합니다. 참가 상태·경고·Discord
원문·기존 로그·백업은 별도입니다. 경고 정정·삭제 등 추가 요청은 내전 관리자에게
비공개로 문의하며 관리자는 경고 전용 채널의 `/경고`에서 취소·전체삭제합니다.
전용 연락처를 정하면 봇 설정과 아래 안내를 함께 갱신해야 합니다.

- 운영자: 미정
- 오류·악용 신고: 미정
- 개인정보 문의·수정·삭제 요청: 미정

## 접수 설계

공개 채널에 개인정보를 남기지 않는 접수 경로를 마련해야 합니다. 아래는 운영
절차 제안이며 현재 제공 중인 접수 양식은 아닙니다.

- 요청 종류와 본인 Discord 사용자 ID
- 필요한 최소한의 본인 확인 방법
- 관련 서버·내전 시각·메시지 링크 등 대상을 찾는 데 필요한 정보
- 수정·삭제 범위와 안전하게 답변받을 경로

비밀번호·봇 토큰·Discord 인증 토큰·신분증 사본을 요청하지 않습니다. 로그나
스크린샷의 관련 없는 사람 정보와 인증 정보는 가리도록 안내합니다.

## 준비할 처리 절차

1. 접수 사실과 필요한 보완 정보를 안내합니다.
2. 타인 정보가 처리되지 않도록 최소 범위에서 요청자를 확인합니다.
3. 원문·참가·연결·알림·로그·백업의 대상을 확인합니다.
4. 진행 중 이벤트와 재시작·복원이 정보를 재생성하지 않도록 안전하게 처리합니다.
5. 완료 범위, 백업 처리와 남는 정보가 있다면 그 근거를 설명합니다.

처리 책임자와 목표 시간은 미정입니다. 참가 취소나 Discord 원문 삭제를 전체
개인정보 삭제 완료로 안내하지 않습니다. 안전한 처리 수단이 구현되기 전에는
운영 DB를 임의의 SQL로 수정하는 것을 표준 절차로 삼지 않습니다.
