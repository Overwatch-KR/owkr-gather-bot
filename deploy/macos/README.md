# Mac 백업 자동 정리

사용자별 LaunchAgent를 만들어 1시간 간격과 로그인 시 `scripts/retention.py --backups`를 실행한다. `--apply`를 생략하면 미리보기다. Python 실행 파일과 스크립트는 캐시·가상환경이 아닌 영구 경로에 복사하고, PC가 잠자거나 로그아웃 중이면 다음 가동 때 확인한다. 서버 백업과 별개의 로컬 복사본에만 적용하며 자동 외부 복사를 뜻하지 않는다.

현재 운영 경로는 `~/Library/Application Support/OWKR/backups/oracle-tokyo`이며 사용자 권한의 정리 스크립트와 LaunchAgent로 관리한다. 생성 기록과 이름의 시각이 일치하는 완성 백업만 생성 후 7일에 만료된다. 잘못된 생성 기록·심볼릭 링크가 있으면 전체 정리를 중단하고 오류를 확인한다. 미리보기로 대상 확인 후 활성화하며, 백업 복사 작업 중에는 정리 서비스를 일시 중지한다. 복사 실패로 남은 미완성 폴더는 자동 삭제 대상으로 보지 않고 운영자가 확인한다.
