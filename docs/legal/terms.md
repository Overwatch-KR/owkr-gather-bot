## 봇과 관리자의 역할

봇은 반응 수신 순서·중복, 참가자 구분, 메시지 연결, 알림과 복구를 처리합니다.
개최·취소, 대타 모집 여부, 예외 참가, 분쟁과 제재는 관리자가 판단합니다.
경고는 다른 관리자와 상의한 후 노쇼·비매너로 직접 기록·조회·취소합니다.
자동 판정·제재·참가 제한은 제공하지 않습니다. 기록은 재적 중 보관하며 탈퇴 확인
또는 관리자 전체삭제로 정리합니다.

기본 정원은 10명이며 이후 참가자는 대기자가 됩니다. 정원이 찬 뒤 확정 참가자가
빠져도 자동 승격하지 않습니다. 대타는 관리자가 명시적으로 모집합니다.
티어는 해당 내전 안내에 답장하여 제출합니다.
서로 다른 시작 시각의 내전은 동시에 예약할 수 있지만, 정확히 같은 시작 시각의
활성 내전은 하나만 허용합니다. 시작 시각부터 반응·티어 자동 처리를 중단하며
미작성자·전원 작성 완료를 자동으로 공개 멘션하지 않습니다.

## 이용 시 유의사항

Discord 약관·커뮤니티 가이드라인과 서버 운영 규칙을 준수해야 합니다.
티어에는 운영에 필요한 게임 정보만 작성하고 비밀번호·인증 토큰이나 불필요한
개인정보를 입력하지 않아야 합니다. 관리자 권한을 무단 제공하거나 원치 않는
멘션·괴롭힘에 봇을 악용해서는 안 됩니다.

## 장애·변경·중단

현재 파일럿은 한국 시간 월~목 20:00~다음 날 02:00, 금~일 24시간 운영합니다.
일요일에서 이어지는 월요일 새벽도 02:00까지 운영하며, 시간 전환에는 약 1분의
지연이 있을 수 있습니다. 비운영 시간에는 명령·반응·티어·알림을 처리하지 않습니다.
정리 작업도 다음 가동 시 수행하며, 중지 중 알림을 모두 소급 전송하지 않습니다.
이 시간대의 내전과 장애 시 수동 진행 여부는 관리자가 판단합니다.

Discord 장애, 권한 변경, 네트워크·운영 환경 문제로 처리가 지연·실패할 수 있습니다.
무료 VM은 제공자의 용량·회수 정책 영향을 받습니다. 자동 재시작과 백업이 연속 가동,
모든 알림의 중복 없는 전달 또는 모든 장애에서의 무손실 복구를 보장하지는 않습니다.
관리자는 상태와 공지를 확인하고 수동 운영 여부를 판단합니다. 운영 변경은 관리자
공지 채널과 공개 안내 웹에 반영하고, 지원 문의는 이메일로 받습니다. 정책 중요 변경의
사전 안내 기간과 서비스 종료 시 데이터 파기 절차는 최종 공개 전에 확정합니다.
