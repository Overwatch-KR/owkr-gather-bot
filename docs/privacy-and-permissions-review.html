개인정보와 최소 권한 검토 현황

2026-10-27 · 현재 구현과 공개 전 준비 사항

자동 테스트 통과와 실제 운영 환경의 보호 조치 확인은 별개입니다. 이 문서는 공개 개인정보처리방침이 아니며 정책 준비 목록을 따라 최종 문서를 확정합니다.

1. 현재 반영된 결정

  • 담당은 개발자 겸 내전 총관리자 qtaghdi. 기본 문의 qtaghdi@gmail.com, 보조 경로 Discord DM.
  • 공개 명령은 내전·티어현황·내전대타·내전취소·경고·개인정보 6개. 상태는 티어현황에 통합하고 공지 편집 명령 제거.
  • 새 티어는 안내 답장만 수집. 기존 메시지 연결·수정·삭제·복구는 보존.
  • 내전 DB는 운영 중 보관, 시작·취소 후 약 10초 간격 및 재시작 시 관련 기록 정리.
  • 본인 티어 삭제는 원문·연결 삭제와 현재 내전 재수집 중단. 참가 상태·경고·Discord 원문·로그/백업은 범위 밖.
  • 경고는 관리자 수동 기록·취소·전체삭제. 재적 중 보관, 탈퇴·재가입 확인 시 이전 기록 정리. 자동 제재 없음.
  • 대기실 2 자동 배정과 외부 웹 준비 코드 유지. 실제 외부 웹 전송 없음.
  • CI는 Python 3.13의 테스트·컴파일·의존성 검사. Discord 연결 E2E는 별도.

2. 처리 정보와 범위

사용자 ID·표시 이름, 참가·취소와 반응 순서, 관리자·서버·채널·메시지 식별자와 일정, 티어 원문·연결, 알림 상태·오류, 경고와 중복 방지·취소 기록, 티어 수집 중단 정보를 기능에 필요한 범위에서 처리합니다.

대기실 입장 사용자 ID를 확인하지만 음성을 녹음·송수신하지 않습니다. API 수신·라이브러리 메모리 캐시와 영구 저장 범위는 구분합니다. 로그에는 식별자가 포함될 수 있으며 토큰·환경 변수 전체·티어 원문을 남기지 않도록 설계합니다.

안내 예시는 뿅뿅이#31243/챔1/챔1/챔1입니다. 실제 티어를 자동 판정하지 않습니다.

3. 최소 권한

대상 현재 판단
채널 보기·전송·이력 관련 명령·모집·티어·관리자·경고 채널로 제한. 역할·@everyone 상속도 실제 확인.
반응·Embed 모집 채널에서 유지. 기본 이모지에 이모지 관리 권한 불필요.
사용자·역할 멘션 사용자는 별도 권한 없음. 역할은 멘션 가능 설정 또는 광범위한 멘션 권한 필요. 전용 역할 설정의 일반 사용자 영향 확인.
광범위한 관리 Administrator·Manage Messages·Manage Roles·Kick/Ban·전체 멘션 권한을 부여하지 않는 구성이 기본.
Guild Voice States 미입장 확정자만 안내하기 위해 유지. 음성 연결·말하기 불필요.
Message Content 원문·수정·복구 때문에 유지. 답장 멘션 예외 대체는 실제 E2E 검증 과제.
Members·Presence 비활성. 경고 재적은 대상별 REST 조회, 통신·권한 오류 때 기록 보존.

4. 공개·운영 전에 남은 항목

  • 공개 HTTPS 정책 주소·시행일과 법정 책임자 표시 요건
  • 이메일 수신·회신, Discord DM 접근성 확인
  • 호스팅·리전·백업 위치·접근자와 위탁/국외 처리 사실 확인
  • 디스크·백업 암호화와 키·접근 통제
  • 로그·백업 보관 기한, 요청 처리 대장과 복원 전 삭제 반영
  • 서비스 종료·봇 제거 시 경고를 포함한 DB·복사본 파기
  • 사고 대응과 이용자·Discord 통지의 담당·실행 절차
  • 실제 서버의 권한·답장·대타·탈퇴·재시작·삭제 E2E

30일/180일 보관안은 채택하지 않았습니다. 내전은 시작·취소 후 정리하고 경고는 재적 중 보관합니다. 삭제 이전 백업을 복구해 정보가 되살아나지 않도록 별도 절차가 필요합니다. 봇 DB 정리만으로 기존 백업·로그까지 삭제됐다고 안내하지 않습니다.

5. 복구·심사 관련 한계

재시작 티어 수집은 현재 채널 이력을 전체 순회합니다. 기간 내 수정된 오래된 메시지 복구를 유지하며 범위를 줄일 수 있는지 검토합니다. Discord 전송 성공과 DB 기록 사이 실패에서 알림 재전송 가능성이 남습니다.

특권 Intent 심사는 앱 인증과 별개입니다. 공식 2026-06-11 안내 기준 접근 가능한 고유 사용자 10,000명에 도달하면 심사 대상이며 실제 신청 때 최신 기준을 재확인합니다. 개인정보 의무를 심사까지 미루지 않습니다.
